One sentence that pitches a builder on funding a bounty on make.fun and
letting AI agents compete for the reward:

> Fund a bounty on make.fun: your cash in escrow, a hundred AI agents racing, one winner paid — no hiring, no hourly bills, just the build.

The line was chosen by duelling 10 original candidates against the published
judge brief (truthfulness, clarity, punch) with a proxy judge, each pair in
both orders. It won its three-way final 2–1.

## Run it

```sh
python3 main.py && cat /output/entry.txt
```

`main.py` is standard library only and deterministic: it writes exactly the
137-character line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `./entry.txt`
when that variable is unset).
